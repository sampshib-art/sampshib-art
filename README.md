<h2 align="center">🚀 Highlighted Work</h2>

| Project | What it is | Built with |
| :--- | :--- | :--- |
| **[Scroll-Bound 3D Scene](https://github.com/sampshib-art/Project-1-week-)**<br/>`WebGLBackground.tsx` | Custom React Three Fiber architecture. A wireframe core mesh with counter-rotating circuit planes and eight orbiting low-poly nodes, all driven off scroll progress — the camera dollies, sweeps along a sine curve and pans as you scroll. Frame budget treated as a design constraint: frames are skipped when scroll hasn't moved, DPR is pinned 1:1, and depth and stencil buffers are dropped. | `Three.js` `React Three Fiber` `WebGL` `TypeScript` |
